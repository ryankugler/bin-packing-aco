Algorithm settings

α = 0 turns learning off, so ants sample from the heuristic alone. Higher β makes them greedier. Evaporation is the share of pheromone lost each round. The same seed always gives the same result.

How the colony got there

Each round, every ant builds a full layout. The best one leaves pheromone on the choices it made, and the next ants lean toward those choices.

Convergence

Score is Σ(sheet fill²) ÷ sheets, plus a small bonus for a big leftover piece on the last sheet. Higher is better. Vertical ticks mark pheromone resets after the colony stalled.

Decisiveness

Average entropy of each ant's choices: 1 means every candidate was equally likely, 0 means the ant always knew what to pick. It falls as pheromone builds up.

Pheromone map

Row = the box just placed (or a fresh sheet). Column = the box placed next. Darker cells are trails the colony reinforced; ants following a dark cell are more likely to repeat that pairing.

Replay the winning ant

τ = pheromone on “previous box → this box”, as a share of the cap. η = heuristic: bigger boxes and boxes that fill their gap snugly score higher. P ∝ τα·ηβ. Dashed outlines show where each candidate would land.

Method notes

What an ant does

  • Looks at every box type still to place and finds where it would fit best on the open sheet (MaxRects, best short-side fit, both orientations if rotation is allowed).
  • Scores each with pheromone τ and heuristic η, then draws one at random in proportion to ταηβ.
  • When nothing else fits, it closes the sheet and starts a new one.

How the colony learns

  • Pheromone sits on pairs: “after box A, place box B”. Identical boxes share one type, so what one learns applies to all copies.
  • Max-Min Ant System: all trails evaporate, only the round's best ant deposits (the all-time best every 5th round), and trails stay between a floor and a cap so no option dies out.
  • If 25 rounds pass with no improvement, trails reset to the cap and the search restarts.

Changes from v1

  • Pheromone tracks what ants actually packed, on “after A, place B” pairs, so the colony can learn ordering.
  • Each ant builds its layout independently.
  • The heuristic is balanced with pheromone instead of outweighing it.
  • The layout shown is the one the colony found.
  • Continuous placement adds decimal sizes, kerf, units and multiple sheets.

How to use SheetFit

  1. Pick your units. Inches, feet, millimetres, centimetres or metres. Fractions work, like 23 1/4. You can also type a unit after any number, like 600mm.
  2. Enter your sheet size. If you're cutting, set the gap to your saw blade's width so every box comes out full size.
  3. List your boxes. Give each size a name, its width and height, and how many you need. Tick ↻ if it can be turned sideways.
  4. Press Find best layout. You'll see each sheet with every box drawn in place, plus how much material is used and wasted.

Not sure where to start? Pick one of the examples under the button. Curious how the layout was chosen? The Advanced tab shows the algorithm's work step by step.
